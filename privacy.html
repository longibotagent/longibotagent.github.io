LongiBot

Privacy policy

This policy covers LongiBot, the command-line tool described on the home page, and the Google user data it accesses.

Data it accesses

After the account's owner signs in and grants access, LongiBot can access, in that Google account:

  • Gmail: messages, attachments, labels and mail settings, to read, compose, send and organize mail.
  • Google Calendar: calendars and events, to read, create and change them.
  • Google Drive: files and folders, to read, upload, organize and share them.
  • Google Contacts: contacts, to read and update them.
  • Basic profile: the account's email address and name, to show which account is signed in.

How it uses that data

LongiBot accesses this data only when its user runs a command, and only to carry out that command, for example sending a message the user wrote or listing the events of a day. Results are shown to the user on their own computer.

Where data is stored

LongiBot has no server. Its sign-in is stored encrypted on the user's computer. Data a command retrieves stays on that computer unless the user saves or sends it elsewhere. No data is sent to the developer or to any server operated for LongiBot.

Sharing

LongiBot does not sell Google user data, does not use it for advertising and does not share it with anyone, except as the user directs (for example sending a message, sharing a Drive file, or passing a command's output to other software the user chooses to run with it, under that software's own terms) or where the law requires it.

Machine learning

LongiBot does not use Google user data to develop, improve or train generalized artificial intelligence or machine-learning models.

Limited Use

LongiBot's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The account's owner can remove LongiBot's access at any time on the third-party connections page of their Google Account. Signing out of LongiBot removes its stored sign-in from the computer. Data already saved on the computer stays there until the user deletes it.

Changes and contact

Changes to this policy are published on this page with a new date. Questions about it go to the support address shown on LongiBot's Google sign-in screen.
