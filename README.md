# longibotagent.github.io

Source of <https://longibotagent.github.io/>: the home page and privacy
policy that the Branding page of the LongiBot Google Cloud project links to.
GitHub Pages serves the default branch as it is (`.nojekyll`, no build), so a
push to `main` is live within a minute or two.

The privacy policy must keep describing what the OAuth grant can reach.
When a scope is added to or removed from the grant, update the "Data it
accesses" list in `privacy.html` and its "Last updated" date in the same
change.
